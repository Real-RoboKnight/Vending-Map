# Vending-Map

A website to locate items in vending machines and other shops near the user.

## Scope

Mobile oriented web app.
User can search for a product, api returns list of products sorted by distance
or price.
They can then be taken to a map app to get there.

Users can also upload vending machine images, where the server will then auto
classify products and prices, the user will be prompted to fix errors, and then
the data will be saved in the database.
